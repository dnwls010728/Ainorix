# OwnEngine API reference

Generated by `oe api --markdown`. The same commands are available through `oe exec`, HTTP `POST /api/call` and MCP tools (dots become underscores).

## tilemap

### `tilemap.layer_get`

Read tilemap layers and the legacy map.

| arg | type | required | description |
|---|---|---|---|
| `id` | integer \| string | yes | Tilemap. |

### `tilemap.layer_set` *(undoable edit)*

Append, change, move or remove an entry of Tilemap.layers (or replace the base map, layer -1); scene undo.

| arg | type | required | description |
|---|---|---|---|
| `id` | integer \| string | yes | Tilemap. |
| `layer` | integer | yes | -1 = the base map; 0.. = Tilemap.layers; layers.size appends. |
| `values` | object |  | name, map, layer, order, ySort, ySortOffset, visible, collision; patches the existing fields. |
| `remove` | boolean |  | Remove this entry of Tilemap.layers. |
| `moveTo` | integer |  | Move this entry of Tilemap.layers to that index (draw order inside a sorting layer). |
| `merge` | string |  | Undo group key. |

### `tilemap.cell_get`

| `row` | integer | yes | Row. |

## sprite

### `sprite.collision` *(undoable edit)*

Set the sprite's Collider2D polygon in local world units (scene undo): its points, or with `frame` the outline used while that frame shows (Collider2D.framePoints).

| arg | type | required | description |
|---|---|---|---|
| `id` | integer \| string | yes | Sprite. |
| `points` | array |  | 3..64 [x,y] points (required unless clear). |
| `frame` | integer \| string |  | Frame index or atlas frame name: write framePoints[frame] instead of points. |
| `clear` | boolean |  | With frame: remove that frame's outline, so the frame uses points again. |
| `merge` | string |  | Undo group for point dragging. |

### `sprite.outline` *(undoable edit)*

Fit a convex Collider2D polygon around the opaque pixels of the sprite's current frame (scene undo). Returns the points. `frame` / `frames` / `allFrames` fit those frames instead and store each one in Collider2D.framePoints.

| arg | type | required | description |
|---|---|---|---|
| `id` | integer \| string | yes | Sprite entity. |
| `alphaCutoff` | number |  | Pixels with at least this alpha count as solid (default 0.5). |
| `maxPoints` | integer |  | Corners kept, 3..8 (default 8: the most a Box2D polygon takes). |
| `frame` | integer \| string |  | One frame (index or atlas frame name) to fit into framePoints. |
| `frames` | array |  | Several frames to fit into framePoints. |
| `allFrames` | boolean |  | Fit every frame of the sheet or atlas (at most 1024) into framePoints. |
| `merge` | string |  | Undo group key. |

### `skeleton2d.draft_template`

A starting rig draft for a kind of character: joints (with where each goes), bones and parts in draw order. With an image, joints and regions are first guesses from its opaque bounds and body proportions, to correct with image.grid.

| arg | type | required | description |
|---|---|---|---|

### `skeleton2d.build`

Build a skeleton asset from a rig draft: cut each part out of the illustration, mesh it, weight it to its bones, place it so the setup pose is the picture. Keeps the clips of an existing asset. Returns coverage (pixels no part took), warnings and a picture of the draft.

| arg | type | required | description |
|---|---|---|---|
| `draft` | string |  | *.skel2d-draft.json to build from (or values). |
| `values` | object |  | The draft itself; with draft it is also written there. |
| `out` | string | yes | *.skel2d.json to write. |
| `partsDir` | string |  | Folder for the cut part images (default: <out name>-parts/). |
| `dryRun` | boolean |  | Only check and draw the draft picture; write nothing else. |
| `draftImage` | string |  | PNG for the draft picture (default .oe/vision/draft.png). |

### `skeleton2d.overlay`

| arg | type | required | description |

| `id` | integer \| string |  | Entity whose Skeleton2D (asset, skin, clip, time) is drawn. |
| `clip` | string |  | Clip to pose (default: the entity's, or the setup pose). |
| `time` | number |  | Seconds into the clip. |
| `skin` | string |  | Skin to show. |
| `weights` | string |  | Bone whose weights tint the vertices: blue 0 .. red 1. |
| `mesh` | boolean |  | Draw mesh edges and vertices (default true). |
| `labels` | boolean |  | Name the bones (default true). |
| `size` | integer |  | Longer side of the picture, 128..2048 (default 768). |
| `out` | string |  | PNG path in the project (default .oe/vision/skeleton.png). |

## image

### `image.grid`

Draw a zoomed coordinate grid over (part of) an image so an agent can read pixel positions exactly; marks show where it thinks points are. Writes a PNG to read.

| arg | type | required | description |
|---|---|---|---|
| `path` | string | yes | Project image (png/jpg/...). |
| `rect` | array |  | [x, y, w, h] in image pixels (default: the whole image). |
| `step` | integer |  | Grid spacing in image pixels (default: about 30 lines across). Every fifth line is yellow and labeled. |
| `scale` | integer |  | Zoom: output pixels per image pixel, 1..32 (default: up to about 1024 pixels wide). |
| `marks` | array |  | Points to draw: [[x, y, "label"], ...] in image pixels (check a guess). |
| `out` | string |  | PNG path in the project (default .oe/vision/grid.png). |

## vision

### `vision.calibrate`

Check that you read image coordinates accurately before rigging: without answers, draws labeled dots at secret positions; with answers {A:[x,y],...}, scores them (pixel error, pass/fail).

| arg | type | required | description |
|---|---|---|---|
| `seed` | integer |  | Layout seed (default 1); the same seed draws the same dots. |
| `count` | integer |  | Number of dots, 3..12 (default 6). |
| `size` | integer |  | Image size in pixels, 128..1024 (default 384). |
| `answers` | object |  | Your readings: {"A": [x, y], ...}, the centre of each dot in image pixels (x right, y down). |
| `tolerance` | number |  | Largest error that passes, in pixels (default 3). |
| `out` | string |  | PNG path in the project (default .oe/vision/calibrate.png). |

## sprite

### `sprite.create`

Make a sprite asset (*.sprite.json) from an image: cut into frames by `slicing` (default: the whole image is one frame), with pixels per unit, filtering and the default pivot every Sprite naming it (Sprite.asset) shares. Or write `values` as given. File write, no scene undo.

| arg | type | required | description |
|---|---|---|---|
| `path` | string | yes | Output .sprite.json. |
| `texture` | string |  | Image to cut. |
| `slicing` | object |  | {mode: cellSize (cellWidth, cellHeight) | cellCount (columns, rows) | auto (gap: parts closer than this many pixels are one sprite), offset: [x, y] margin, spacing: [x, y] gutters, trim: cut cells to their opaque pixels}. |
| `pixelsPerUnit` | number |  | Image pixels per world unit (default 16). |
| `pixelArt` | boolean |  | Sharp nearest-neighbour pixels (default true). |
| `pivot` | array |  | [x, y] 0..1 point of each frame at the entity position (default [0.5, 0.5]; [0.5, 0] = feet). |
| `prefix` | string |  | Frame name prefix (default: the file name and _). |
| `values` | object |  | Complete definition instead of texture/slicing. |
| `overwrite` | boolean |  | Replace an existing file. |
| `dryRun` | boolean |  | Return what would be written without writing it. |

### `sprite.get`

Read a sprite asset: `values` as written, `resolved` with defaults filled in (every frame's pivot), the image size.

| arg | type | required | description |
|---|---|---|---|
| `path` | string | yes | .sprite.json. |

### `sprite.set`

Change a sprite asset: merge `values` into it (pixelsPerUnit, pixelArt, pivot, normalTexture, texture, frames), or with `frame` into that frame (name, pivot, collision in frame pixels). A null value removes the field (a frame's pivot or collision goes back to the default). Validated before writing; no scene undo.

| arg | type | required | description |
|---|---|---|---|
| `path` | string | yes | .sprite.json. |
| `values` | object | yes | Fields to merge; null removes one. |
| `frame` | integer \| string |  | Frame index or name to change instead of the asset. |

### `sprite.slice`

Cut a sprite asset's image into frames again with new `slicing` settings. Frames that keep their name (the same cell) keep their pivot and collision. `dryRun` previews the frames. No scene undo.

| arg | type | required | description |
|---|---|---|---|
| `path` | string | yes | .sprite.json. |
| `slicing` | object | yes | As sprite.create. |
| `prefix` | string |  | Frame name prefix (default: the one the frames have, else the file name and _). |
| `dryRun` | boolean |  | Return the frames without writing. |

### `sprite.fit_collision`

Trace collision outlines around the opaque pixels of sprite asset frames (the largest part of each frame) and store them in the asset; Collider2D shape sprite then collides with them. No frame arguments = every frame. No scene undo.

| arg | type | required | description |
|---|---|---|---|
| `path` | string | yes | .sprite.json. |
| `frame` | integer \| string |  | One frame (index or name). |
| `frames` | array |  | Several frames. |
| `alphaCutoff` | number |  | Pixels with at least this alpha are solid (default 0.5). |
| `detail` | number |  | How far in pixels the outline may stray from the pixel edges to need fewer corners (default 1; 0 = every step). |
| `convex` | boolean |  | The convex hull instead of the traced outline (smoother sliding, fewer pieces). |
| `dryRun` | boolean |  | Return the outlines without writing. |

### `sprite.convert` *(undoable edit)*

Move a sprite's image settings (Sprite.asset as an image or atlas with settings, e.g. "hero.png?columns=6&pivot=0.5,0") into a new sprite asset and point Sprite.asset at it. A polygon Collider2D becomes shape sprite with its outlines (framePoints, else points) stored per frame. `all` also points every other Sprite drawing the same image the same way at the asset. Scene undo (the file stays).

| arg | type | required | description |
|---|---|---|---|
| `id` | integer \| string | yes | Sprite entity. |
| `path` | string | yes | New .sprite.json. |
| `all` | boolean |  | Also convert the other sprites with the same image settings. |
| `overwrite` | boolean |  | Replace an existing file. |

## atlas

### `atlas.create`

Write a named sprite atlas, normalize TexturePacker JSON, or slice a grid; no scene undo.

| arg | type | required | description |
|---|---|---|---|
| `path` | string | yes | Output .atlas.json. |
| `values` | object |  | Atlas or TexturePacker definition. |
| `source` | string |  | TexturePacker JSON to read (image resolves beside source). |
| `texture` | string |  | Grid image to slice. |
| `cellWidth` | integer |  | Slice width in pixels. |
| `cellHeight` | integer |  | Slice height in pixels. |
| `trim` | boolean |  | Grid: cut each cell to its opaque pixels, keeping the cell as the original size so frames do not jump; empty cells are skipped. |
| `auto` | boolean |  | Instead of a grid, find each sprite of `texture` by the transparent space around it (top to bottom, left to right). |
| `gap` | integer |  | auto: parts closer than this many pixels are one sprite (default 2). |
| `pivot` | array |  | [x, y] pivot of every frame, 0..1 like Sprite.pivotX/Y ((0.5, 0) = bottom center). |
| `offset` | array |  | Grid: [x, y] pixels before the first cell (sheet margin). |
| `spacing` | array |  | Grid: [x, y] pixels between cells (gutters). |
| `prefix` | string |  | Frame name prefix (default frame_). |
| `overwrite` | boolean |  | Replace existing file. |
| `dryRun` | boolean |  | Return the frames that would be written without writing the file (slicing previews). |

## Component types

### Transform

Position, rotation (Euler degrees, applied X then Y then Z) and scale relative to the parent entity.

| field | type | default | description |
|---|---|---|---|
| `position` | vec3 | `[0,0,0]` | Local position in meters. +Y is up. |
| `rotation` | vec3 | `[0,0,0]` | Local rotation as Euler angles in degrees. |
| `scale` | vec3 | `[1,1,1]` | Local scale factors. |

### MeshRenderer

Draws a mesh: a built-in shape (cube, sphere, plane, plane64, pyramid, quad) or a glTF model file. Unknown meshes render as a magenta cube.

| field | type | default | description |
|---|---|---|---|
| `mesh` | string | `"cube"` | Built-in name (cube, sphere, plane, plane64 = plane split into 64x64 cells for shader graph vertex offsets, pyramid, quad) or model path, e.g. "assets/models/fox.glb" (.glb/.gltf/.fbx). |
| `material` | string | `""` | Material file (*.mat.json: PBR color/metallic/roughness/normal/emissive maps, transparency) used for every part of the mesh. Empty = the model's own materials (glTF) or the default (white, roughness 0.7). |
| `materials` | json | `[]` | Material files per material of a model, in the order asset.info lists its `materials` (their `name` says which part): ["materials/face.mat.json", "", ...]. An empty or missing entry keeps `material`, or the model's own when that is empty. |
| `blendShapes` | json | `{}` | Weights of the model's blend shapes (morph targets), {name: weight}: {"E_Close": 1} closes the eyes, 0.5 half way; several add up. asset.info lists a model's `blendShapes`; unknown names are ignored. Scripts animate faces by setting this every frame. |
| `shaderUniforms` | json | `{}` | Per-entity values for the material's shader graph uniforms: {name: number or [x, y, z, w]}. Unnamed uniforms keep the material's values; scripts can change them every frame. An unknown name or a material without a graph renders magenta. |
| `color` | color | `[0.800000012,0.800000012,0.800000012]` | Tint multiplied with the material/texture color, linear RGB 0..1 (or "#rrggbb"). |
| `opacity` | float | `1` | Below 1 the mesh is drawn transparent (alpha blended, sorted back to front, no shadow). |
| `texture` | string | `""` | Image (.png/.jpg) overriding the material's base color texture. Empty = use the material's. |
| `shading` | string | `"smooth"` | smooth = interpolated vertex normals, flat = faceted. |
| `unlit` | bool | `false` | Ignore lighting and shadows (UI-like, emissive look). Overrides the material. |
| `castShadows` | bool | `true` | Casts shadows from the directional light. |
| `visible` | bool | `true` | Whether the mesh is drawn. |
| `parentPose` | bool | `false` | Draw this model in the pose of the parent entity, which must show the same model: a second layer of a character (an outline shell, a glow) follows its Animator, BoneIK goals and SpringBones. |

### Animator

Fixed-step glTF TRS animation on the entity's MeshRenderer; clips are listed by asset.info.

| field | type | default | description |
|---|---|---|---|
| `clip` | string | `""` | Exact model clip name; empty = default pose. animation.play changes clips and restarts by default. |
| `speed` | float | `1` | Playback multiplier; negative plays backwards, zero holds the pose. |
| `loop` | bool | `true` | Wrap time at the clip duration; otherwise clamp and stop at either endpoint. |
| `playing` | bool | `true` | Advance time while true; false holds the current pose. |
| `time` | float | `0` | Seconds into the clip; set to seek. Direct clip edits preserve time. |
| `blend` | float | `0` | Seconds a change of `clip` takes: the pose fades from the old clip (which keeps playing) to the new one instead of jumping. 0 = at once. 0.2 suits idle/walk/run. |

### BoneAttachment

Holds this entity on a bone of its parent's model (weapon in a hand, hat on a head): after physics each frame its Transform position and rotation are set from the posed bone, IK included. Bone names: animation.bones.

| field | type | default | description |
|---|---|---|---|
| `bone` | string | `""` | Exact node name in the parent's MeshRenderer model; an unknown name leaves the Transform alone. |
| `position` | vec3 | `[0,0,0]` | Offset from the bone in the bone's own axes, in model units. |
| `rotation` | vec3 | `[0,0,0]` | Rotation offset from the bone (Euler degrees). Transform.scale stays yours. |

### BoneIK

Inverse kinematics goal for its parent's model: the bones above `bone` turn so that it reaches this entity's Transform position (move the entity to move the hand or foot). Applied after the Animator's clip in both renderers; goals run in entity id order.

| field | type | default | description |
|---|---|---|---|
| `bone` | string | `""` | Exact name of the node that should reach the goal (hand, foot, head); see animation.bones. |
| `chain` | int | `2` | How many bones above it turn, 1..8. 2 = an arm or a leg (exact two-bone solve); 1 aims the parent bone; more bend a spine or tail step by step. |
| `weight` | float | `1` | 0 = the animated pose, 1 = reach the goal; between blends the goal position. |
| `pole` | vec3 | `[0,0,0]` | chain 2: direction in model space the elbow or knee points to, e.g. [0,0,1]; [0,0,0] keeps the side the limb bends to in the model's default pose. |
| `soften` | float | `0` | chain 2: share of the limb length (0..0.5) over which it eases into full extension, so a goal near or beyond reach does not snap the limb straight; the bone then stops slightly short of such goals. 0 = exact reach. Try 0.1 for feet. |
| `keepRotation` | bool | `false` | The bone keeps the orientation the clip gave it while the limb above it is solved; otherwise it turns with the limb. On for feet and hands whose goal only corrects a clip (foot placement): the ankle or wrist does not twist when the knee or elbow ends up elsewhere. |
| `turn` | vec3 | `[0,0,0]` | Turns the bone by these Euler degrees around the model's axes on top of the orientation the pose gives it (scaled by weight): a foot tilted to the slope it stands on, from a script. Without matchRotation. |
| `matchRotation` | bool | `false` | Also turn the bone to this entity's Transform rotation (a foot flat on a slope, a palm on a wall). |

### SpringBone

Secondary motion for bones of its parent's model (tail, ears, hair, a cape strip): `bone` and every bone below it lag behind and swing as the character moves, then settle back into the animated pose. Simulated after physics each fixed step while playing, on top of the Animator's clip and BoneIK; stopped scenes show the plain pose.

| field | type | default | description |
|---|---|---|---|
| `bone` | string | `""` | Exact name of the first bone that swings (tail root, ear base, first hair bone); the whole branch below it follows. A name ending in * takes every branch whose bones start with that text ("Bone_Skirt*": all strips of a skirt with one component). See animation.bones. |
| `stiffness` | float | `100` | Pull back to the animated pose. 20 = loose and slow (long hair, cloth), 100 = a tail, 400+ = short stiff parts (ears, antennae). 0 = hangs freely. |
| `damping` | float | `10` | How fast the swing dies out, per second. 3 = long wobble, 10 = one soft overshoot, 25+ = follows late without swinging back. A clip that already moves these bones in a rhythm (a walk) gets exaggerated when this is low; raise it together with stiffness. |
| `gravity` | vec3 | `[0,0,0]` | World-space acceleration in m/s^2, e.g. [0,-9.8,0] so the chain sags; [0,0,0] keeps the authored pose at rest. Other directions act as steady wind. |
| `weight` | float | `1` | 0 = the animated pose, 1 = the simulated swing; between blends them. |
| `radius` | float | `0.0199999996` | Thickness of the swinging bones in meters when they meet a SpringCollider of the same model. |
| `limit` | float | `0` | Largest angle in degrees a bone may swing away from its animated direction; 0 = no limit. 25-40 keeps hair and cloth from standing out sideways when the character starts, stops or jumps. Colliders may push further. |
| `air` | float | `0` | Share of the damping that works against the air instead of against the pose, 0..1. At 0 a damped bone moves with the character; above 0 it trails behind while the character moves and falls back when it stops: hair and cloth streaming in a run. Try 0.05-0.15; the trail grows with speed, damping and this value, and shrinks with stiffness. |
| `collide` | bool | `true` | Whether the SpringColliders of the model stop these bones. Off for parts that hang clear of them (long hair behind legs that have colliders for the skirt). |
| `endLength` | float | `0` | Meters of mesh that hang below the last bone of each branch (the hem of a skirt, hair tips). Above 0 the last bones swing and collide too, as if they had a bone that far along them; 0 = they stay rigid on the bone above. |

### SpringCollider

A body part that the SpringBones of its parent's model do not pass through: a sphere at `bone`, or a capsule from `bone` to `tail` (thigh to calf, calf to foot) so a raised leg lifts a skirt instead of cutting through it. A child of the model entity, like SpringBone. It moves with the pose (clip + BoneIK); it is not a physics collider.

| field | type | default | description |
|---|---|---|---|
| `bone` | string | `""` | Exact name of the bone the collider sits on. See animation.bones. |
| `tail` | string | `""` | Second bone: the collider is a capsule between the two. Empty = a sphere at `bone`. |
| `radius` | float | `0.0599999987` | Radius in meters. Larger than the limb: the cloth between two swinging strips is not simulated. |
| `offset` | vec3 | `[0,0,0]` | Moves the collider, in the model's own axes and meters (e.g. [0,0,0.03] = forward). |

| `order` | int | `0` | Lower draws first, higher covers it. First sixteen visible enabled boxes by order then entity id. |
| `enabled` | bool | `true` | Enable this box projector; disabled decals cost no atlas/sample work. |

### CameraFollow

Moves this entity (usually the camera) to target + offset after physics each frame and aims it at the target.

| field | type | default | description |
|---|---|---|---|
| `target` | entity | `0` | Entity id to follow. |
| `offset` | vec3 | `[0,4,8]` | Position relative to the target (world axes). |
| `lookOffset` | vec3 | `[0,0.5,0]` | Point to look at, relative to the target. |
| `smoothing` | float | `8` | Catch-up speed (per second); 0 = snap instantly. |
| `useBounds` | bool | `false` | Clamp the camera position to boundsMin..boundsMax and keep its rotation (2D side-scrollers: the view stops at the level edges). |

| `boundsMax` | vec3 | `[1000,1000,1000]` | Highest camera position when useBounds is on. |

### Sprite

Draws a frame of an image on a quad facing +Z, placed at the entity. The image and what every copy shares (frames, pixels per unit, pivots, filtering, collision outlines) come from asset: a sprite asset (*.sprite.json, edited in the Sprite Editor) or an image path. Transparent pixels are cut out. For 2D games use an orthographic Camera looking down -Z.

| field | type | default | description |
|---|---|---|---|
| `drawMode` | string | `"simple"` | simple, tiled (repeat at the asset's pixels per unit), or sliced (9-slice). |
| `slice` | float | `0` | 9-slice border in source-frame pixels; corners retain source world size. |
| `fill` | float | `1` | Visible fraction, 0..1. |
| `fillMode` | string | `"horizontal"` | horizontal from left, vertical from bottom, radial clockwise from top. |
| `mask` | entity | `0` | Another sprite entity: clip to its sampled alpha in world space; zero disables. Mask chains are not followed. |
| `maskOnly` | bool | `false` | Provide a sprite mask without drawing the source sprite. |
| `light2D` | bool | `false` | Lit by Light2D in mode color/add (the scene's 2D light map, sampled per pixel) instead of scene lights. |
| `ambient2D` | color | `[0.150000006,0.150000006,0.150000006]` | Light a light2D sprite gets everywhere (where no Light2D reaches). |
| `ySort` | bool | `false` | Sort by screen-space pivot Y within the layer, lower pivots in front. |
| `ySortOffset` | float | `0` | Offset added to the sort pivot in camera-up world units. |
| `asset` | string | `""` | What the sprite draws. A sprite asset (*.sprite.json, sprite.create / the Sprite Editor): its image, frames, pixels per unit, filtering, each frame's pivot and collision outline, shared by every sprite naming it. Or an image directly: "coin.png" (whole image, 16 px per unit, centered, pixel art), with settings after it: "hero.png?columns=6&rows=1&ppu=16&pivot=0.5,0&pixelArt=0&normal=hero_n.png" (a grid of frames), or an atlas "hero.atlas.json?ppu=32". Empty = a plain 1 x 1 quad. |
| `material` | string | `""` | Optional material file (*.mat.json) for the sprite's quad, e.g. a shader graph whose `offset` sways it or `fog: false`. The asset's image stays its base image (graph uv includes the frame); the sprite's own cutoff, blend, lit, tint and emission still apply. Empty = the default sprite material. |
| `color` | color | `[1,1,1]` | Tint multiplied with the image. |
| `frame` | frame | `0` | Frame index or frame name in the asset (SpriteAnimation sets it). |
| `width` | float | `0` | Width in world units (0 = frame pixels / the asset's pixels per unit). Transform.scale multiplies it. |
| `height` | float | `0` | Height in world units (0 = from pixels). |
| `flipX` | bool | `false` | Mirror horizontally (face left). |
| `flipY` | bool | `false` | Mirror vertically. |
| `alphaCutoff` | float | `0.5` | Pixels with alpha below this are not drawn. 0 = soft edges: the image's alpha is blended (smoke, glows, UI-like art). |
| `opacity` | float | `1` | Below 1 the sprite is drawn see-through (alpha blended). |
| `lit` | bool | `false` | Apply scene lighting (default: full brightness, like classic 2D). |
| `emission` | float | `0` | Lit sprites: this fraction of the image's own colour is added whatever the lighting, so sprites seen against the light (night, backlit) stay readable. 0 = none. |
| `blend` | string | `"alpha"` | alpha = normal; add = the image brightens what is behind it (glows, fire, light beams) and is always blended. |
| `layer` | int | `0` | 2D sorting layer: sprites of a higher layer are drawn in front of lower ones at the same depth, whatever their position on screen (background 0, characters 1, effects 2, ...). |
| `order` | int | `0` | Sorting inside the layer: higher is drawn in front. |
| `castShadows` | bool | `false` | Cast a shadow shaped by the image (texels below alphaCutoff cast none). Needs lit: true and a cut-out sprite (alphaCutoff > 0); the sprite is then drawn from both sides. |
| `visible` | bool | `true` | Whether the sprite is drawn. |

### SpriteAnimation

Plays frame sequences on the entity's Sprite. clips = {"run": {"frames": [2,3,4,5], "fps": 10, "loop": true}}; set clip to switch (restarts it).

| field | type | default | description |
|---|---|---|---|
| `asset` | string | `""` | Shared .anim.json definition (sheet or rectangle atlas plus clips/events); takes precedence over inline clips. Empty keeps legacy scenes. |
| `loopOverride` | int | `-1` | Asset clip loop override: -1 = clip default, 0 = once, 1 = repeat. Inline clips use their own loop field. |
| `clips` | json | `{}` | Clip name -> {frames: [indices], fps: number, durations: optional seconds per sequence frame (overrides fps), loop: bool (default true), events: [{frame: sequenceIndex, name: string}]}. animation.events lists/sets markers; onAnimationEvent(name, clip) receives crossings and finished. |
| `clip` | string | `""` | Clip being played. Changing it starts the new clip from its first frame. |
| `speed` | float | `1` | Playback speed multiplier. |
| `playing` | bool | `true` | Pause/resume. |
| `time` | float | `0` | Runtime: seconds into the current clip. |
| `finished` | bool | `false` | Runtime: true once a non-looping clip reached its last frame. |

### Tilemap

Grid of tiles written as text rows (map): each character is a tile defined by a tileset file or the legend (fixed frame, random variants or autotile that picks frames from the neighbours). The entity position is the top-left corner; rows go down (-Y), columns right (+X). Tiles can be solid, one-way or shaped (slopes) for 2D and 3D physics.

| field | type | default | description |
|---|---|---|---|
| `layers` | json | `[]` | Additional map layers [{name,map,layer,order,ySort,ySortOffset,visible,collision}]; same tileset. Cells may be strings or {tile,flipX,flipY,rotation:0|90|180|270}. |
| `layer` | int | `0` | Sorting layer of the legacy map. |
| `order` | int | `0` | Sorting order of the legacy map. |
| `ySort` | bool | `false` | Sort each tile by its bottom-center pivot against sprites. |
| `ySortOffset` | float | `0` | Camera-up offset added to each cell sort pivot. |
| `tileset` | string | `""` | Tileset: an image (grid of equally sized tiles, see columns/rows) or a *.tileset.json file (image, grid and tile rules shared by maps). |
| `columns` | int | `1` | Tiles per row in the tileset image (ignored with a .tileset.json). |
| `rows` | int | `1` | Rows of tiles in the tileset image (ignored with a .tileset.json). |
| `tileSize` | float | `1` | Size of one tile in world units. |
| `map` | json | `[]` | Array of strings, one per row from the top; one character per tile. Characters without a rule (space, '.') are empty. |
| `legend` | json | `{}` | Character -> rule; overrides the tileset file. A rule is a frame number or {frame, variants, autotile: "sides"|"blob", frames, connects, edges, collision}, e.g. {"#": {"autotile": "blob", "frame": 0, "collision": "solid"}, "=": {"frame": 47, "collision": "oneway"}}. |
| `solid` | string | `""` | Characters that collide as full blocks, e.g. "#=" (shortcut for collision: "solid"). |
| `color` | color | `[1,1,1]` | Tint. |
| `pixelArt` | bool | `true` | Sharp nearest-neighbour pixels. |
| `lit` | bool | `false` | Apply scene lighting. |
| `light2D` | bool | `false` | Lit by Light2D in mode color/add (the 2D light map) instead of scene lights. |
| `ambient2D` | color | `[0.150000006,0.150000006,0.150000006]` | Light the light2D tiles get everywhere (where no Light2D reaches). |
| `visible` | bool | `true` | Whether the tiles are drawn (they still collide). |

### NavMesh

| field | type | default | description |
|---|---|---|---|

| `color` | color | `[1,1,1]` | Tint multiplied with every part. |
