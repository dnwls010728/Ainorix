# OwnEngine API reference

Generated by `oe api --markdown`. The same commands are available through `oe exec`, HTTP `POST /api/call` and MCP tools (dots become underscores).

## engine

### `engine.info`

Engine version, platform, project, scene and simulation status.

## api

### `api.list`

List all commands with their argument schemas.

| arg | type | required | description |
|---|---|---|---|
| `verbose` | boolean |  | Include full JSON schemas (default true). |

### `api.batch`

Run several commands in order and return every result.

| arg | type | required | description |
|---|---|---|---|
| `calls` | array | yes | Array of {command: string, args: object}. |
| `stopOnError` | boolean |  | Stop at the first failing call (default true). |

## log

### `log.get`

Read engine log entries newer than a sequence number.

| arg | type | required | description |
|---|---|---|---|
| `since` | integer |  | Return entries with seq > since (default 0). |
| `limit` | integer |  | Max entries (default 200). |

## scene

### `scene.summary`

Compact list of entities: id, name, parent, component names.

### `scene.get`

Full scene document (the exact JSON that is saved to disk).

### `scene.new` *(undoable edit)*

Replace the current scene with an empty one (camera + light included by default).

| arg | type | required | description |
|---|---|---|---|
| `name` | string |  | Scene name. |
| `empty` | boolean |  | Skip the default camera and light. |

### `scene.load`

Load a scene file (path relative to the project directory).

| arg | type | required | description |
|---|---|---|---|
| `path` | string | yes | Scene file path, e.g. "scenes/main.scene.json". |

### `scene.save`

Save the scene to disk. While simulating, the pre-simulation scene is saved.

| arg | type | required | description |
|---|---|---|---|
| `path` | string |  | Target path relative to the project (default: current scene path). |

### `scene.list`

List scene files in the project directory.

### `scene.rename` *(undoable edit)*

Rename the scene.

| arg | type | required | description |
|---|---|---|---|
| `name` | string | yes | New scene name. |

## entity

### `entity.create` *(undoable edit)*

Create an entity, optionally with components and a parent.

| arg | type | required | description |
|---|---|---|---|
| `name` | string |  | Entity name (should be unique so it can be referenced by name). |
| `parent` | integer \| string |  | Parent entity id or name. |
| `components` | object |  | Map of component type -> field values, e.g. {"Transform": {"position": [0,1,0]}}. |

### `entity.get`

Full data of one entity (all components and values).

| arg | type | required | description |
|---|---|---|---|
| `id` | integer \| string | yes | Entity id or name. |

### `entity.find`

Find entities by name substring, component type and/or tag.

| arg | type | required | description |
|---|---|---|---|
| `name` | string |  | Case-insensitive substring of the entity name. |
| `component` | string |  | Only entities that have this component type. |
| `tag` | string |  | Only entities whose Tag component contains this tag. |

### `entity.delete` *(undoable edit)*

Delete an entity and all of its children.

| arg | type | required | description |
|---|---|---|---|
| `id` | integer \| string | yes | Entity id or name. |

### `entity.rename` *(undoable edit)*

Rename an entity.

| arg | type | required | description |
|---|---|---|---|
| `id` | integer \| string | yes | Entity id or name. |
| `name` | string | yes | New name. |

### `entity.set_parent` *(undoable edit)*

Re-parent an entity (parent 0 = scene root).

| arg | type | required | description |
|---|---|---|---|
| `id` | integer \| string | yes | Entity id or name. |
| `parent` | integer \| string | yes | New parent id/name, or 0 for root. |

### `entity.duplicate` *(undoable edit)*

Duplicate an entity (and its children) next to the original.

| arg | type | required | description |
|---|---|---|---|
| `id` | integer \| string | yes | Entity id or name. |
| `name` | string |  | Name for the copy. |

## component

### `component.types`

All component types with documentation and JSON schemas of their fields.

### `component.add` *(undoable edit)*

Add a component to an entity (values are optional overrides of the defaults).

| arg | type | required | description |
|---|---|---|---|
| `id` | integer \| string | yes | Entity id or name. |
| `type` | string | yes | Component type name. |
| `values` | object |  | Field values. |

### `component.set` *(undoable edit)*

Change some fields of an existing component (partial update).

| arg | type | required | description |
|---|---|---|---|
| `id` | integer \| string | yes | Entity id or name. |
| `type` | string | yes | Component type name. |
| `values` | object | yes | Field values to change. |

### `component.remove` *(undoable edit)*

Remove a component from an entity.

| arg | type | required | description |
|---|---|---|---|
| `id` | integer \| string | yes | Entity id or name. |
| `type` | string | yes | Component type name. |

## sim

### `sim.state`

Simulation state: playing, frame, time, keys held.

### `sim.play`

Start (or resume) real-time simulation. The scene is snapshotted first.

### `sim.pause`

Pause real-time simulation (state is kept).

### `sim.stop`

Stop simulating and restore the scene from before play/step started.

### `sim.step`

Advance the simulation by N fixed 1/60 s frames (deterministic).

| arg | type | required | description |
|---|---|---|---|
| `frames` | integer |  | Frames to simulate (default 1, max 36000). |

## input

### `input.key`

Press or release a key ("W", "A", "S", "D", "Space", "Left", ...).

| arg | type | required | description |
|---|---|---|---|
| `key` | string | yes | Key name. |
| `down` | boolean |  | true = press (default), false = release. |

### `input.clear`

Release all keys.

## render

### `render.screenshot`

Render a frame and return it as PNG (and/or save it). Look at it to verify visual changes.

| arg | type | required | description |
|---|---|---|---|
| `width` | integer |  | Image width in pixels (default 640). |
| `height` | integer |  | Image height in pixels (default 360). |
| `camera` | object |  | Optional free camera {eye:[x,y,z], target:[x,y,z], fov:degrees}. Default: the scene's active camera. |
| `grid` | boolean |  | Draw the editor ground grid (default false). |
| `highlight` | integer |  | Entity id to outline. |
| `path` | string |  | Also write the PNG to this path (relative to the project). |
| `inline` | boolean |  | Return the PNG as base64 in png_base64 (default true when no path is given). |

### `render.pick`

Return the entity visible at a pixel of a rendered view.

| arg | type | required | description |
|---|---|---|---|
| `width` | integer |  | Image width in pixels (default 640). |
| `height` | integer |  | Image height in pixels (default 360). |
| `camera` | object |  | Optional free camera {eye:[x,y,z], target:[x,y,z], fov:degrees}. Default: the scene's active camera. |
| `grid` | boolean |  | Draw the editor ground grid (default false). |
| `highlight` | integer |  | Entity id to outline. |
| `x` | integer | yes | Pixel x (0 = left). |
| `y` | integer | yes | Pixel y (0 = top). |

### `render.meshes`

Names of the built-in meshes usable in MeshRenderer.mesh.

## history

### `history.undo`

Undo the last scene edit (not available while simulating).

### `history.redo`

Redo the last undone edit.
