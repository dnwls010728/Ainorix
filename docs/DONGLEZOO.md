# 동글 동물원 (Dongle Zoo) — 게임 기획서

`games/DongleZoo` 에 구현된 모바일 캐주얼 머지 퍼즐의 기획·수익화·출시 문서.
구현 구조는 [games/DongleZoo/README.md](../games/DongleZoo/README.md), 작업 현황은 이 문서 끝의 작업 로그를 본다.

## 1. 한 줄 소개

동글동글한 동물을 병에 떨어뜨려, 같은 동물 둘이 만나면 한 단계 큰 동물로 합쳐지는 세로형 물리 퍼즐.
병아리에서 시작해 고래까지 키우는 것이 목표다.

## 2. 왜 이 게임인가 (시장·수익 근거)

| 기준 | 판단 |
|---|---|
| 남녀노소 | 규칙이 한 문장(같은 것끼리 합친다), 글을 못 읽어도 플레이 가능, 폭력·경쟁·시간 압박 없음, 한 손 조작 |
| 검증된 장르 | "수박 게임"류 드롭 머지는 장르 전체가 장기 흥행 중. 세션이 짧고(3~8분) 반복 플레이 동기가 강하다 |
| 수익 구조 적합성 | 게임오버 직전의 "한 번만 더" 심리와 보상형 광고가 자연스럽게 맞물린다. 강제 결제 없이 광고만으로 성립 |
| 제작 비용 | 콘텐츠가 동물 11종 + 배경 3종으로 작다. 물리(Box2D)·UI·세이브는 엔진에 이미 있다 |
| 차별점 | 과일이 아닌 표정 있는 동물 캐릭터(도감 수집), 일일 미션·출석 보상으로 재방문 유도, 아이템 3종으로 막힌 판 구제 |

## 3. 대상과 플랫폼

- 대상: 전 연령(만 4세 이상 조작 가능). 핵심층은 10~40대 캐주얼 이용자, 부모·자녀 동반 플레이.
- 플랫폼: Android(세로 고정), 웹(H5 포털·자체 페이지). Windows 빌드는 개발·검증용.
- 화면: 720×1280 기준 설계. 좁은 화면(9:19.5 등)은 병 위쪽 여백이 늘고, 넓은 화면(태블릿·PC)은 좌우에 배경이 보인다.
  어느 비율에서도 병 폭이 화면에 꽉 차게 맞는다 (`scripts/app.lua` `layout`).

## 4. 핵심 플레이

1. 화면을 누른 채 좌우로 끌어 조준, 손을 떼면 동물이 떨어진다.
2. 같은 동물 둘이 닿으면 합쳐져 다음 단계 동물이 되고 점수를 얻는다.
3. 다음에 나올 동물은 오른쪽 위 "다음" 칸에 보인다 (1~5단계 중 가중 무작위).
4. 동물이 빨간 점선 위에 2초 이상 머무르면 게임 종료.

### 동물 11단계

| 단계 | 동물 | 반지름(유닛) | 만들 때 점수 |
|---|---|---|---|
| 1 | 병아리 | 0.26 | – |
| 2 | 햄스터 | 0.34 | 1 |
| 3 | 토끼 | 0.45 | 3 |
| 4 | 고양이 | 0.52 | 6 |
| 5 | 강아지 | 0.66 | 10 |
| 6 | 여우 | 0.80 | 15 |
| 7 | 판다 | 0.92 | 21 |
| 8 | 곰 | 1.08 | 28 |
| 9 | 사자 | 1.25 | 36 |
| 10 | 코끼리 | 1.43 | 45 |
| 11 | 고래 | 1.62 | 55 |

- 고래 둘이 합쳐지면 둘 다 사라지고 +100 ("고래 파티").
- 콤보: 1초 안에 연속으로 합쳐지면 점수 ×(1 + 0.25 × (콤보−1)), 최대 +150%.
- 병: 안쪽 폭 6.6, 바닥에서 점선까지 8.4 유닛. 가장 큰 고래 지름이 병 폭의 약 49%.

수치는 모두 `scripts/lib/defs.lua` 한 파일에 있다.

### 도움 아이템

| 아이템 | 효과 | 코인 가격 |
|---|---|---|
| 뿅망치 | 누른 동물 하나를 없앤다 | 120 |
| 흔들기 | 병을 흔들어 동물을 다시 자리 잡게 한다 | 80 |
| 요술봉 | 누른 동물을 한 단계 키운다 | 150 |

처음에 각 2개 지급. 다 쓰면 코인으로 사거나 보상형 광고로 1개를 받는다.

## 5. 메타 게임 (재방문 장치)

| 장치 | 내용 |
|---|---|
| 코인 | 게임 종료 시 점수 ÷ 30. 새 동물을 처음 만들면 +20 |
| 동물 도감 | 만난 동물이 채워진다. 못 만난 동물은 실루엣 |
| 매일 선물 | 7일 연속 출석 50→60→80→100→120→150→300 코인. 하루 빠지면 1일차로. 광고 보면 2배 |
| 오늘의 미션 | 8종 중 날짜로 정해지는 3개(전 이용자 동일). 달성 시 40~90 코인 |
| 배경 | 햇살 초원(기본), 노을 해변 800, 별빛 밤 1,500 코인 |
| 최고 점수 | 홈과 HUD에 표시, 갱신 시 "신기록!" |

코인 경제(광고 없이 하루 3판, 평균 1,500점 가정): 판당 50 + 출석 평균 120 + 미션 약 170 ≈ 하루 440 코인.
노을 해변은 약 2일, 별빛 밤은 약 4일 차에 열린다. 아이템을 사면 그만큼 늦어져 광고 시청 동기가 생긴다.

## 6. 수익화

| 수단 | 위치 | 원칙 |
|---|---|---|
| 보상형 광고 | 이어하기(판당 1회, 병 위쪽 절반 정리), 코인 2배, 아이템 무료 1개, 매일 선물 2배 | 항상 이용자가 선택. 매출의 중심 |
| 전면 광고 | 게임 종료 후 "다시 하기/홈" 사이 | 세션 첫 2판은 없음, 최소 150초 간격, 플레이 중에는 절대 없음 |
| 광고 제거 (인앱) | 상점, $2.99 | 전면 광고 제거, 보상형 보상은 광고 없이 즉시 지급 |
| 코인 팩 (인앱) | 상점, $0.99 / $3.99 | 1,000 / 5,000 코인 |

배너 광고는 넣지 않는다(오조작과 어린 이용자 문제, 화면 하단이 아이템 영역).

### 전 연령 대응 (스토어 정책)

- Google Play 가족 정책 대상이 될 수 있으므로 광고 SDK는 아동 대상 설정(비개인화, TFCD)으로 요청하고, 가족 정책 인증 네트워크만 쓴다.
- 채팅·외부 링크·계정·개인정보 수집 없음. 세이브는 기기 로컬.
- 인앱 결제는 스토어의 구매 인증(부모 확인)에 맡긴다.

### 구현 상태 — 중요

게임은 광고·결제를 `scripts/lib/ads.lua` 한 곳을 통해서만 부른다. 이 모듈은 엔진의 **호스트 브리지**
(`host.call` / `host.poll`, [GAMEPLAY.md](GAMEPLAY.md#host-application-ads-purchases))로 플레이어를 품은 앱에 요청한다.

- **웹**: `games/DongleZoo/web/host.js` 가 Google H5 Games Ads(AdSense Ad Placement API)에 연결한다.
  `AD_CLIENT` 에 게시자 ID를 넣으면 실제 광고가 나온다. 비어 있으면 데모로 동작한다. 실제 계정으로는 검증하지 못했다.
- **Android**: 플레이어가 Java 없는 NativeActivity라서 광고·결제 SDK를 부를 층이 아직 없다
  (`PlatformHostCall` 이 false). 지금 APK는 데모 오버레이로 동작한다. 실제 수익화에는 Java 액티비티 +
  AdMob/Play Billing 연결이 필요하다 (아래 작업 로그의 미완료 항목).
- **데모 모드**: 호스트가 없으면 같은 흐름이 데모 오버레이로 진행된다(광고 대신 진행 막대, 결제 대신 확인 창).
  실제 광고·과금은 없다. 출시 빌드에서 데모 결제가 코인을 그냥 주지 않게 하려면 `defs.lua` 의 `D.DEMO_STORE = false`.

## 7. 화면 구성

- 홈: 로고, 최고 점수, 시작하기, 상점·도감·미션·선물·설정. 받을 것이 있으면 빨간 점.
- 플레이: 위쪽 코인·점수·최고·일시정지·다음 동물, 가운데 병, 아래 아이템 3개.
- 대화상자: 일시정지, 게임 종료, 상점, 도감, 미션, 매일 선물, 설정, 아이템 부족.
- 언어: 한국어/영어(첫 실행은 기기 언어, 설정에서 전환). 글꼴 Jua(OFL).

## 8. 아트·사운드

- 동물 11종과 앱 아이콘: Codex 이미지 생성 결과(`tools/art_src/codex/`)를 `tools/import_art.py` 로 물리 원에 맞춰 설치.
- 배경·병·이펙트·UI 아이콘: `tools/make_art.py` 가 코드로 그린다(동물 대체본도 포함, 생성 이미지 없이도 완전한 게임).
- 효과음 14종과 배경음악 1곡(35초 루프): `tools/make_audio.py` 합성.

## 9. 출시 체크리스트

1. `D.DEMO_STORE = false`, `web/host.js` 의 `AD_CLIENT` 설정과 `TEST_ADS = false`.
2. `project.json` 의 `android.package`, `versionCode` 확인. 릴리스 키로 `oe package games/DongleZoo --android --aab --keystore ...`.
3. 스토어 등록 정보: 대상 연령, 광고 포함 표시, 개인정보처리방침(수집 없음 명시), 스크린샷(세로).
4. 실기기에서 터치·소리·백그라운드 복귀·세이브 확인.
